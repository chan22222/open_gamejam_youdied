# ESC/APE — 게임 기획서

> **"ESC를 눌러라. 죽음을 밟고 올라가라."**
> 설정 메뉴가 세계의 물리 법칙이고, 실패 화면이 다음 스테이지가 되는 2D 퍼즐 플랫포머.

- 장르: 메타 퍼즐 플랫포머 (싱글플레이, 키보드+마우스)
- 플랫폼: 웹 (Vite + React + Phaser 3 Arcade Physics)
- 플레이타임 목표: 12~20분 (게임잼 빌드)
- 주인공: 고양이 (기존 HIDER 스프라이트 재사용)

---

## 1. 핵심 컨셉 — 두 기획의 융합

### 원작 기획 A: 《설정에서 탈출하라》
설정값(밝기·음량·화면 크기·키 바인딩)이 단순 옵션이 아니라 **세계의 물리 법칙**이다.

### 원작 기획 B: 《YOU DIED?》
실패 화면이 다음 스테이지다. 글자가 발판이 되고, RETRY 버튼을 밀어 쓰고,
사인(死因) 문구에서 단어를 지워 규칙을 바꾼다. **실패는 리셋이 아니라 건축 재료다.**

### 융합 메커니즘: **"죽어야 설정이 열린다"**

게임 시작 시 ESC를 눌러도 설정 메뉴는 **텅 비어 있다** (`NO PERMISSIONS`).
죽을 때마다 사망 공간(Deathspace)에 들어가고, 그곳에서 **사인 단어를 지우면**
그 단어가 **설정 메뉴의 새 항목으로 해금**된다.

| 사인 (죽음) | 사망 공간에서 지우는 단어 | 해금되는 설정 | 세계에 미치는 효과 |
|---|---|---|---|
| `KILLED BY: DARKNESS` | `DARKNESS` | **BRIGHTNESS 슬라이더** | 밝기를 올리면 숨겨진 문/발판이 드러남 |
| `KILLED BY: SOUND` | `SOUND` | **VOLUME 슬라이더** | 음량 0 → 소리에 반응하는 감시자가 잠듦 |
| `KILLED BY: THE FRAME` | `FRAME` | **DISPLAY 슬라이더** | 화면 크기를 줄이면(줌아웃) 화면 밖 발판이 스테이지 안으로 들어옴 |

즉 **실패가 곧 설정 메뉴를 건축한다.** 두 기획의 핵심이 하나의 루프로 결합된다:

```
죽는다 → 실패 화면을 오른다 → 사인 단어를 지운다 → 설정이 해금된다
→ 설정으로 물리 법칙을 바꾼다 → 전진한다 → 새로운 방식으로 죽는다 → …
```

### 축적되는 실패
- 죽은 자리마다 **시체가 영구히 남는다**. 시체는 밟을 수 있는 발판이다.
- 사망 공간에는 죽을 때마다 **RETRY 버튼이 하나씩 더 쌓인다**. 버튼은 눌리지 않는다.
  **밀어서** 계단으로 쓴다.
- 최종 사망 공간의 출구는 높은 곳에 있다 — **충분히 실패한 자만이 올라갈 수 있다.**

## 2. 스테이지 구성 (4막 + 사망 공간들)

### STAGE 0 // 어두운 방 — "설정을 배우는 죽음"
- 거의 완전한 어둠. 희미한 윤곽만 보이는 방. 문은 잠겨 있고 어떤 상호작용도 통하지 않는다.
- 벽의 낙서: `"빛이 없으면 바닥도 없다"`. 앞으로 나아가면 어둠 속 구덩이에 떨어져 사망.
- → **`KILLED BY: DARKNESS`** → 사망 공간 #1 (튜토리얼).
- 사망 공간에서 복귀 후: ESC → BRIGHTNESS 슬라이더 등장 → 밝기를 최대로 올리면
  **숨겨진 문이 벽에서 드러나며 실체화**된다. 구덩이도 보여서 피할 수 있다.
- 가르치는 것: *죽음은 진행이다. ESC는 무기다.*

### 사망 공간 #1 — "YOU DIED?" (튜토리얼)
- 검은 공간에 거대한 `YOU DIED?` 활자가 떠 있다. **글자 위로 올라갈 수 있다.**
- `RETRY` 버튼이 있지만 눌러도 반응 없음(`BUTTON NOT RESPONDING`). **밀 수 있다** —
  밀어서 첫 글자에 닿는 계단으로 쓴다.
- 최상단의 사인 문구 `KILLED BY: DARKNESS`에서 `DARKNESS` 단어 위에 서서 E를 길게 누르면
  단어가 글리치와 함께 소멸 → `KILLED BY: ______` → **BRIGHTNESS 해금 연출** → 복귀.

### STAGE 1 // 소리의 정원 — 감시자
- 총을 든 감시자 고양이(SEEKER)가 순찰한다. 플레이어의 **발소리를 듣는다** —
  발소리의 크기는 **VOLUME 설정값에 비례**한다 (아직 VOLUME이 없으므로 최초엔 무조건 들킨다).
- 들키면 사망: **`KILLED BY: SOUND`** → 사망 공간 #2 → `SOUND` 삭제 → **VOLUME 해금**.
- 해법 (둘 다 유효):
  1. **VOLUME을 0으로** → 세계가 무음이 되고 감시자가 잠든다 (zZ 이펙트). 단, 배경음악도 사라진다 — 침묵의 대가.
  2. 볼륨을 낮춘 채(발소리 반경 축소) Q 위장으로 시야만 피해 은신 통과.
- 사망 공간 #2: 버튼이 2개로 늘었고 이전 시체가 놓여 있다. 더 높은 곳의 단어까지 올라간다.

### STAGE 2 // 프레임의 끝 — 화면 밖은 존재하는가
- 건널 수 없는 대협곡. 협곡 건너편으로 가는 발판들이 **화면 프레임 바깥에** 떠 있는 게
  살짝 보인다 (스테이지 경계가 빛나는 프레임으로 시각화되어 있다).
- 프레임 밖으로 몸을 던지면 사망: **`KILLED BY: THE FRAME`** → `FRAME` 삭제 → **DISPLAY 해금**.
- **DISPLAY 슬라이더를 줄이면 카메라가 줌아웃**되며 프레임이 넓어지고, 바깥에 있던 발판이
  **스테이지 안으로 실체화**된다 (물리 활성화).
- 후반: `DASH MODULE — KEY NOT BOUND` 오브젝트 획득 → 설정의 **CONTROLS 탭 해금** →
  잠겨 있던 대시 액션을 **원하는 키에 직접 바인딩**해야 마지막 대점프 구간을 건넌다.

### STAGE 3 // 관리자 (BOSS: SYS_ADMIN) — 설정을 지켜라
당신이 죽음으로 쌓아 올린 설정 메뉴를, 시스템 관리자가 **회수하러 온다.**

- **페이즈 1 — 방패**: 관리자가 음파탄을 발사한다. **설정 창 자체를 마우스로 드래그해
  방패로 사용**한다. 탄을 막을 때마다 창에 금이 가고(내구도 감소), HUD가 흔들린다.
- **페이즈 2 — 권한 회수**: 관리자가 `REVOKE: BRIGHTNESS` — 세계가 어두워진다.
  이제 **설정 창이 발광체다**. 창을 드래그해 발밑을 비추며 이동한다.
- **페이즈 3 — 파괴**: 설정 창이 산산조각 나 아레나에 흩어진다. 조각(슬라이더, 토글,
  닫기 버튼…)을 주워 **UI를 직접 재조립**한다. 조각 하나를 되찾을 때마다 권한이 하나 돌아온다.
- **페이즈 4 — 예정된 죽음**: 재조립을 끝내면 관리자가 최후의 일격. **`KILLED BY: ADMIN`** —
  피할 수 없는 스크립트 사망.

### 최종 사망 공간 — "탑"
- 지금까지의 **모든 시체와 모든 RETRY 버튼**이 한 공간에 쌓여 탑이 되어 있다.
- 실패의 탑을 올라 최상단의 거대한 `YOU DIED?` 앞에 선다.
- 지울 단어는 사인이 아니다. **`DIED`를 지운다** → **`YOU ?`**
- 물음표를 밟는 순간 화면이 하얗게 —

### 에필로그
- `YOU ?` → `YOU.` 고양이는 집으로 걸어간다. 배경에 모든 시체가 일어나 손을 흔든다.
- 최종 통계: 사망 횟수는 점수다. `DEATHS: 07 — 일곱 번의 건축.`

## 3. 조작

| 입력 | 액션 |
|---|---|
| A / D, ←/→ | 이동 |
| SPACE | 점프 (코요테 타임 + 점프 버퍼) |
| E (길게) | 상호작용 / 단어 삭제 |
| Q (홀드) | 배경 위장 |
| **ESC** | **설정 = 세계 파라미터** |
| 마우스 드래그 | 설정 창 이동 (보스전: 방패/광원) |
| (플레이어 지정) | 대시 — CONTROLS에서 직접 바인딩해야 사용 가능 |

## 4. 비주얼 / 오디오 방향
- 픽셀아트 + CRT 프레임(스캔라인·비네트), 채도 낮은 초록-청록 세계 vs 사망 공간의 흑·적·상아.
- 사망 공간의 활자는 세리프(비석 느낌), 시스템 텍스트는 모노스페이스.
- 음악·효과음은 전부 WebAudio 합성(외부 에셋 0). **게임 내 VOLUME 슬라이더가 실제 마스터 볼륨** —
  설정과 세계가 같은 값을 공유한다는 것을 소리로 증명한다.
- 밝기 슬라이더도 실제 화면 밝기에 반영 — 설정이 "진짜 설정"처럼 동작하면서 세계를 바꾼다.

## 5. 디자인 원칙
1. **모든 설정값은 반드시 세계와 UI 양쪽에 동시에 영향을 준다.** (가짜 옵션 금지)
2. **죽음은 항상 전진이다.** 게임오버 화면에 재시작 버튼은 없다 — 있더라도 밀어서 쓰는 물건이다.
3. **힌트는 세계 안에 낙서로 존재한다.** 튜토리얼 팝업 금지.
4. 퍼즐마다 해법은 1~2개, 발견의 주체는 항상 플레이어.
