# ESC/APE

> "ESC를 눌러라. 죽음을 밟고 올라가라."

설정 메뉴가 세계의 물리 법칙이고, 실패 화면이 다음 스테이지가 되는 **메타 퍼즐 플랫포머**입니다.
게임을 시작하면 ESC를 눌러도 설정 메뉴는 텅 비어 있습니다 (`NO PERMISSIONS`).
죽을 때마다 사망 공간에서 사인(死因) 단어를 지우면, 그 단어가 설정 메뉴의 새 항목으로 해금됩니다.

```
죽는다 → 실패 화면을 오른다 → 사인 단어를 지운다 → 설정이 해금된다
→ 설정으로 물리 법칙을 바꾼다 → 전진한다 → 새로운 방식으로 죽는다 → ...
```

- 밝기 슬라이더는 실제 화면 밝기이자, 숨겨진 문을 실체화하는 광원입니다.
- 볼륨 슬라이더는 실제 마스터 볼륨이자, 감시자가 듣는 발소리의 크기입니다.
- 디스플레이 슬라이더는 카메라 줌이자, 화면 밖 발판을 스테이지 안으로 끌어오는 프레임입니다.
- 시체는 발판이고, 눌리지 않는 RETRY 버튼은 밀어서 쓰는 계단입니다. 사망 횟수는 점수입니다.

## 실행

```bash
npm install
npm run dev
```

프로덕션 빌드는 `npm run build`이며 결과물은 `dist/`에 생성됩니다.

## 조작

| 입력 | 액션 |
|---|---|
| `A / D` 또는 방향키 | 이동 |
| `SPACE` | 점프 (코요테 타임 + 점프 버퍼) |
| `E` (길게) | 상호작용 / 사인 단어 삭제 |
| `Q` (홀드) | 배경 위장 |
| `ESC` | **설정 = 세계 파라미터** |
| 마우스 드래그 | 설정 창 이동 (보스전에서는 방패이자 광원) |
| (플레이어 지정) | 대시 — CONTROLS 탭에서 직접 키를 바인딩해야 사용 가능 |

## 구조

- 4개 스테이지(어두운 방 → 소리의 정원 → 프레임의 끝 → 관리자 보스전)와
  죽을 때마다 진입하는 사망 공간(Deathspace), 그리고 실패의 탑 엔딩으로 구성됩니다.
- React가 CRT 셸 / HUD / 설정 패널을, Phaser 3 Arcade Physics가 세계와 사망 공간을 담당합니다.
- 음악과 효과음은 전부 WebAudio 합성입니다 (외부 오디오 에셋 없음).
